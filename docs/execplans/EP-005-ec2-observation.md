# EP-005：実EC2の観測接続

状態：計画。実装進捗は着手時に更新する。

## 目的
実EC2の観測接続を、根拠とテストで確認できる成果へ分割する。

## 開始条件
コンテナでの観測対象・操作・必要能力・権限の取り決めがあり、接続対象が承認済みである。

## 実施することと理由
1. 環境能力、IAM/OS権限、named collector、承認digestを実装する。
2. 利用可能なSSM等の輸送方式を実対象で確認し、接続先を識別する。
3. AMI、OS、JDK、Tomcat、WAR/JAR、設定等を取得可能範囲で観測する。
4. 観測Deploymentとdesired stateとの差をFindingへ変換する。

観測に必要な能力・権限・承認の扱いを先に実装し、実対象で接続方式と接続先を確認する。その後、取得可能な観測結果をdesired stateと比較する。

## 完了条件
- [ ] 誤account/region/instanceに対して操作前に停止する。
- [ ] observe環境でreset/seedの要求が実行されない。
- [ ] 秘密値を除去した観測証跡が保存される。
- [ ] SSM未対応の場合に承認済み代替手順と未確認範囲を示せる。

## PRと証跡
データや操作の仕様、実装、fixture、統合確認をレビュー可能な単位へ分ける。各PRに変更理由、入力Snapshot、実行コマンド、結果、未確認事項を残す。

## 中断・復旧
最後に検証できたcommitとRun/Attemptを記録し、再開時に入力digestと権限を再確認する。外部状態の復元は対象Providerの承認手順で行う。

## 進捗・判断・引継ぎ
着手後に実施済み事項、発見、Decision、残課題、次の作業を日付付きで追記する。
