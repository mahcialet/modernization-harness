# EP-001：独立調査の実行管理

状態：計画。実装進捗は着手時に更新する。

## 目的
独立調査の実行管理を、根拠とテストで確認できる成果へ分割する。

## 開始条件
EP-000で定めたデータ形式・必須項目・参照関係と固定Snapshotが利用できる。

## 実施することと理由
1. 最初にfake AgentアダプタでA/B/Cの別入力・別出力を検証する。
2. Copilot CLIの導入版、help、指示ファイル、セッション・権限制御を実測しアダプタへ閉じ込める。
3. 別process・worktreeまたは読取snapshot・出力権限で独立性を実装する。
4. 全成功Attemptを封印してDへ渡す合流条件と、再試行・取消・resumeを実装する。

まずfake Agentで入力と出力の分離を検証し、導入版で確認したCopilot CLIの能力に合わせて実アダプタと合流・再試行を実装する。

## 完了条件
- [ ] 各系列から他系列の報告を参照できないテストが通る。
- [ ] 3系列の入力SHA集合と共通質問が一致する。
- [ ] 1系列失敗時にDが通常の完全結果として起動せず、再試行できる。
- [ ] 実Copilotを許可環境で起動した証跡と、未確認能力を記録する。

## PRと証跡
データや操作の仕様、実装、fixture、統合確認をレビュー可能な単位へ分ける。各PRに変更理由、入力Snapshot、実行コマンド、結果、未確認事項を残す。

## 中断・復旧
最後に検証できたcommitとRun/Attemptを記録し、再開時に入力digestと権限を再確認する。外部状態の復元は対象Providerの承認手順で行う。

## 進捗・判断・引継ぎ
着手後に実施済み事項、発見、Decision、残課題、次の作業を日付付きで追記する。
