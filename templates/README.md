# 配布テンプレート

`system-ops`は独立したシステム管理リポジトリを生成する。
`application-overlay`は既存アプリへ追加する候補ファイルを生成する。
後者は一時ディレクトリへ展開して既存規約と比較し、必要なファイルだけをPRで取り込む。
既存アプリのルートにinitを実行する方式では扱わない。

各template.jsonのfilesに、配布するファイルとそれぞれの所有区分を定義する。
配布対象と所有区分を判断するときは、この定義を基準とする。
managedは差分更新対象、seedは導入後にシステム側が所有する初期設定である。
基準ファイルとlockは適用した内容の追跡に使う。
