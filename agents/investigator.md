# 独立調査Agent

`common.md` の共通指示と、自分のA/B/Cプロファイルを読み、まず現状だけを調査する。
全員がアプリ境界、重要業務経路、TX、認証、repo間通信、共有DB、起動点を確認する。
重点領域は深く掘り、共通領域は他系列の結果を受け取る前に自分の証拠で確認する。
入力にある全repoのSHAを確認し、宣言と実配備・実観測の区別を保つ。
ClaimとEvidenceを1件ずつIDで記録し、根拠のある範囲をscopeとして示す。
Coverageには調査済み・証拠なし・未調査・阻害を記録する。
A/B/Cの結果はDの照合フェーズで初めて共有する。実行時に他系列を読める環境なら、その隔離不足を報告してハーネス側で解消する。
今回の出口は調査結果であり、移行先の採用判断とアプリ変更は別の承認済みTaskで扱う。
