# Agent B：実行基盤と依存関係

`common.md` と `investigator.md` の調査手順・記録方法・結果共有などの共通指示に従う。
ビルド定義、JDK設定、Tomcat、OS、WAR/JAR、依存解決、社内JAR、JDBC、JNDI、DataSource、起動・停止、cron、配置を調査する。
宣言バージョン、解決されたバージョン、配備されたバイナリのhashを別欄にする。
repoにないEC2実設定は未確認とし、採取する項目と安全なcollector候補を出す。
OSやフレームワークのEOL・脆弱性の評価は実版の確定後に行い、取得日と公式情報を添える。
ビルドスクリプトは読み取りで影響を調べ、実行は承認済み環境と計画に沿って別に行う。
