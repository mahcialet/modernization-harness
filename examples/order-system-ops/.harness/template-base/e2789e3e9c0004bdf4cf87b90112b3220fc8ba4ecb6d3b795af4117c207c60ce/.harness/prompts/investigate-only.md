# システム現状調査の依頼

対象system-opsの `AGENTS.md`、`AGENTS.project.md`、`system.yaml`、`repositories.lock.yaml` を読み、現状調査だけを実施してください。
最初にrepo群の参照権限と完全SHAを確認し、System Snapshotを固定してください。
A/B/Cは共通の重要領域を重複確認し、独立セッションと出力先で調査してください。
実行機能が未整備の場合は各系列の指示・入力・出力先を作り、人が独立セッションで起動できる形にしてください。
各系列の成功Attemptが揃ったらDにまとめて渡し、一次情報で照合してください。
現行のソース・設定・実行環境は維持し、調査成果と未確認事項を日本語で保存してください。
ビルドやEC2観測が必要なら、必要権限と副作用を含む追加調査計画に分けてください。
最終成果は根拠付きInventory案、依存グラフ案、Unknown、Coverage、比較Scenario候補です。
