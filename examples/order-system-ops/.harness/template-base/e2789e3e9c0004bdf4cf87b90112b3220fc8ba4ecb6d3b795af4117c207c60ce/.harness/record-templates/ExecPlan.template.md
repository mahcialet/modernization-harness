# ExecPlan：作業名

状態：計画。関連Taskと入力Snapshotを記入する。

## 目的と理由
業務・技術上の成果と、この作業が必要な理由を示す。

## 開始条件
承認Decision、依存Task、対象repo/SHA、必要環境と能力を示す。

## 実施する作業
レビュー可能なPR単位に分け、各段階の成果と検証を示す。

## 完了条件
実行できる受入条件と必要な証跡を示す。

## 復旧
戻す範囲、戻せるデータ状態、残る副作用、復旧確認を示す。

## 実施したこと
対象、作業、結果、根拠、判断を実施日付きで追記する。

## 次に実施すること
残課題、必要な判断、次の開始条件と理由を記録する。
